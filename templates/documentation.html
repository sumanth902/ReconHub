ReconHub Documentation

Unified OSINT & Footprinting Framework

What is ReconHub?

ReconHub is a security reconnaissance and OSINT framework designed to collect and analyze information about authorized targets from multiple security and intelligence sources.

It combines multiple reconnaissance techniques into a single unified platform, helping security researchers understand the attack surface of a target.

Reconnaissance Modules

WHOIS

Domain ownership and registration information.

DNS Lookup

DNS records and enumeration.

Subdomains

Discover subdomains associated with a target.

Technology Fingerprinting

Detect frameworks, CMS platforms and technologies.

Security Headers

Analyze HTTP security headers.

SSL Certificate

Collect SSL/TLS certificate information.

Wayback Machine

Find historical website snapshots.

Google Dorks

Generate advanced search queries.

Open Ports

Identify accessible network ports.

Email Security

Analyze SPF, DKIM and DMARC.

CVEs

Identify vulnerability information related to detected technologies.

GeoIP

Identify geographic information associated with an IP address.

How to Use ReconHub

  1. Login to your ReconHub account.
  2. Select the target type.
  3. Enter an authorized domain, IP address, email or username.
  4. Click Start Recon.
  5. ReconHub runs the available reconnaissance modules.
  6. Review the reconnaissance results and risk score.
  7. View previous scans from History.
  8. Access generated PDF and JSON reports.

Risk Score

ReconHub analyzes the collected information and generates an overall risk score between 0 and 100.

0–30

Low Risk

31–70

Medium Risk

71–100

High Risk

Reports

ReconHub can generate reports containing reconnaissance results and security information.

  • PDF Report
  • JSON Report

Responsible Use

ReconHub should only be used against systems, domains, IP addresses and accounts that you own or have explicit authorization to test.

Unauthorized reconnaissance or security testing may violate laws, policies or terms of service.
